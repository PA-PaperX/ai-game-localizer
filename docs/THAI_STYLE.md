# แนวทางการแปลภาษาไทยสำหรับเกมทั่วไป

เอกสารนี้เป็นหลักการกลาง เจ้าของแต่ละโปรเจกต์ต้องกำหนดอภิธานศัพท์ กลุ่มผู้เล่น และเสียงของตัวละครจากเกมนั้นก่อนแปล ไม่มีสรรพนาม ระดับความหยาบ หรือแนวเสียงที่บังคับใช้กับทุกเกม

## บริบทมาก่อนสำนวน

ค้นและบันทึกฉาก ผู้พูด ผู้ฟัง ความสัมพันธ์ เหตุการณ์ก่อนหน้า สิ่งที่อ้างถึง และเจตนาของบท ตาม [ขั้นตอนค้นบริบท](CONTEXT_RESEARCH.md) จากนั้นจึงเลือกคำไทย คำอังกฤษเหมือนกันอาจต้องแปลต่างกันเมื่อใช้คนละฉาก

แยกข้อมูลที่เห็นในบท/ภาพเกมออกจากข้ออนุมาน หากข้อสงสัยทำให้ความหมายเปลี่ยน ให้พักบรรทัดนั้นและหาหลักฐานก่อนแปล ไม่เติมความแน่นอนให้ฉากที่ยังไม่รู้

## สรรพนามและเสียงตัวละคร

เลือกตามฐานะ ความสนิท อายุ ตัวตน และน้ำเสียงที่มีหลักฐาน ไม่ถือว่าตัวร้ายทุกคนต้องใช้ “มึง” ผู้เล่นทุกคนต้องใช้ “แก” หรือผู้พูดทางการทุกคนต้องใช้ “ผม”

you ไม่ระบุเพศหรือจำนวนด้วยตัวเอง ตรวจผู้ฟังและรูปแบบตัวละครที่ผู้เล่นเลือกได้ก่อนใช้คำบอกเพศหรือคำลงท้าย เมื่อยังไม่ยืนยัน อาจละสรรพนามหรือใช้ถ้อยคำเป็นกลางโดยไม่เปลี่ยนความหมาย รักษาเพศและความสัมพันธ์ที่บทระบุจริง

ทำตารางเสียงเป็นรายเกม: ผู้พูด → ผู้ฟัง → ความสัมพันธ์ → สรรพนาม → ระดับภาษา → หลักฐานฉาก หากความสัมพันธ์เปลี่ยนระหว่างเรื่อง ให้บันทึกช่วงที่เปลี่ยนด้วย

## ระดับภาษาและเนื้อหา

รักษาความสุภาพ ความหยาบ อารมณ์ขัน ความรุนแรง การเสียดสี และนัยตามต้นฉบับกับแนวทางโปรเจกต์ เกมครอบครัว แฟนตาซี การเมือง สืบสวน หรือสยองขวัญใช้แนวเสียงต่างกันได้ ไม่เพิ่มคำด่าและไม่ทำให้บททุกตัวละครพูดเหมือนกัน

เมนูและคำสั่ง: ไทยกระชับ อ่านแล้วรู้ว่าปุ่มทำอะไร ศัพท์สม่ำเสมอแต่ตรวจหน้าที่จริง คำเดียวกันอาจหมายถึงเปิดประตู เปิดเมนู หรือเปิดใช้งานตัวเลือก

## ความต่อเนื่องและรูปแบบ

อ่านบทก่อนหน้า/ถัดไป ตรวจชื่อเฉพาะ คำเรียก ความหมายซ้ำ และมุกที่ปูไว้ รักษาตัวแปร แท็ก รูปแบบจำนวน และเครื่องหมายที่เอนจินใช้ แยกปัญหาความหมายจากฟอนต์และพื้นที่แสดงผล

เครดิตเป็นข้อมูลของแต่ละโปรเจกต์ ใส่เฉพาะตำแหน่งที่เจ้าของม็อดกำหนด ไม่เติมชื่อผู้พัฒนาเครื่องมือลงข้อความเกมโดยอัตโนมัติ
