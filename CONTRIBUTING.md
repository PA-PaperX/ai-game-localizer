# Contributing

Install with `python -m pip install -e .` and run `python -m unittest discover -s tests -v`.

Use synthetic fixture text written for this project. Report game/build and tool versions, exact failure stage and a minimal sanitized reproduction. Do not attach game archives, keys or extracted proprietary corpora.

Prefer format-specific adapters over heuristic text replacement. Preserve original strings, key sets, other languages and unrelated metadata. Structural acceptance, linguistic review, compilation verification and runtime acceptance must remain distinct.

Roadmap: a resource-set manifest, additional PO/XLIFF/native engine text adapters, specialized formatters, optional provider integrations with explicit data-sharing control, and game-specific packaging plugins with tested rollback. These are planned, not implemented features of 0.1.0.
